# نشرة أدوات الذكاء الاصطناعي

صفحة ثابتة (`docs/index.html`) بتتحدّث تلقائيًا مرتين في اليوم عن طريق **GitHub Actions** — من غير أي سيرفر تديره، ومن غير أي تكلفة. الميزة الأساسية عن نسخة Apps Script: الروابط هنا بتفتح عادي 100% لأن الصفحة مش متقدّمة جوه إطار (iframe) مقفول من جوجل.

## الإعداد (مرة واحدة بس)

1. **ارفع الملفات دي على مستودع (repository) جديد** في حسابك على GitHub:
   - اعمل New repository (Public أو Private، الاتنين شغالين).
   - ارفع كل الملفات والمجلدات اللي جوه الملف المضغوط ده بنفس الشكل.

2. **فعّل GitHub Pages:**
   - روح Settings → Pages.
   - تحت "Build and deployment" → Source: اختار **Deploy from a branch**.
   - Branch: اختار `main` والمجلد `/docs`، واحفظ (Save).
   - بعد شوية هيديك لينك شبه: `https://<اسمك>.github.io/<اسم-المستودع>/`

3. **فعّل صلاحية الكتابة لـ Actions** (عشان يقدر يعمل commit للتحديثات):
   - روح Settings → Actions → General.
   - تحت "Workflow permissions" اختار **Read and write permissions**، واحفظ.

4. **شغّل التحديث الأول يدويًا:**
   - روح تاب **Actions** فوق في المستودع.
   - اختار workflow اسمه "Update AI Tools Digest" من القايمة الجانبية.
   - اضغط **Run workflow** (زرار على اليمين) → Run workflow.
   - استنى دقيقة أو اتنين لحد ما تلاقي علامة ✓ خضرا.
   - افتح لينك GitHub Pages بتاعك (من خطوة 2) وشوف الصفحة.

بعد كده الصفحة هتتحدّث لوحدها الساعة ٨ صباحًا و٨ مساءً بتوقيت القاهرة كل يوم، من غير ما تعمل حاجة.

## لو عايز تضيف أو تشيل مصدر / حساب X

عدّل الملف `scripts/generate.js`:
- قايمة `FEEDS` لمصادر الأخبار (RSS).
- قايمة `PEOPLE` لحسابات X.

بعد أي تعديل، اعمل commit، والـ workflow هيشتغل تلقائي في الميعاد الجاي (أو شغّله يدويًا زي خطوة 4).

## ملاحظات مهمة

- التغريدات بتتجاب عن طريق **Nitter** (بديل مجاني غير رسمي لـ X)، وممكن بعض السيرفرات تقف من وقت للتاني — الكود بيجرب أكتر من سيرفر تلقائيًا.
- بعض مواقع الأخبار (زي TechCrunch أو The Verge) أحيانًا بترفض طلبات من سيرفرات سحابية (بروتيكشن ضد البوتات). لو لقيت في سجل الـ Actions إن مصادر كتير بترجع "فشل"، ده طبيعي جزئيًا ومش مشكلة في الكود — الصفحة هتفضل تعرض أي مصدر نجح.
- الإيميل اليومي لسه شغال عن طريق Apps Script بتاعك زي ما هو (منفصل تمامًا عن المشروع ده).
